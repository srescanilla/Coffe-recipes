Coffee Label — BLE Control

Manage the coffee presets stored on the "EtiquetaCafe" e-paper label over Bluetooth.
Safari on iPhone does not support Web Bluetooth in any version. Use the Bluefy app instead (App Store), or open this page on Android Chrome.
Web Bluetooth only works over HTTPS (or on localhost). Opening this file directly from your Downloads folder will not connect — host it (GitHub Pages works fine) and open it from there.
